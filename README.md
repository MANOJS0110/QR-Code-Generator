# QR Code Generator

A responsive, client-side web application built with vanilla HTML, CSS, and JavaScript to convert URLs and custom text strings into instant, scannable QR codes.

---

## Features

- **Real-Time Generation:** Converts text inputs and URLs into QR codes dynamically.
- **Client-Side Processing:** Lightweight execution directly in the browser with no backend server overhead.
- **Responsive Interface:** Clean, mobile-friendly UI styled with CSS3.
- **Universal Scanning:** Compatible with any standard mobile camera scanner or barcode app.

#URL : http://localhost:8080

---

## Tech Stack

- **HTML5:** Semantic document structure and input forms.
- **CSS3:** Responsive layout, centered flexbox card design, and UI styling.
- **JavaScript (ES6):** Dynamic DOM manipulation and QR code rendering logic.
